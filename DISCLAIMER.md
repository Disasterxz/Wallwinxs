# Aviso legal y propósito del proyecto

**Wallwinxs** es un proyecto **educativo y de desarrollo personal**, creado con fines de aprendizaje (Kotlin/Android, Python, empaquetado multiplataforma, consumo de APIs REST, CI/CD con GitHub Actions, etc.). Se distribuye de forma **gratuita** y sin ánimo de lucro.

## Sobre el contenido mostrado

- Wallwinxs **no aloja, no almacena en servidores propios y no redistribuye** ninguna imagen. Es únicamente un **cliente** que consulta la **API pública oficial de [Wallhaven](https://wallhaven.cc)** (`wallhaven.cc/api/v1`) para buscar, previsualizar y descargar fondos de pantalla directamente desde sus servidores.
- Todas las imágenes, miniaturas y metadatos (etiquetas, resolución, categoría, etc.) que se muestran en la app pertenecen a **Wallhaven** y a los **artistas/autores originales** de cada fondo de pantalla. Wallwinxs no reclama ninguna autoría, propiedad ni derecho sobre ese contenido.
- Este proyecto **no busca quitarle méritos, tráfico, ingresos ni derechos a Wallhaven ni a los creadores de los fondos de pantalla**. Wallwinxs no incluye publicidad propia, no monetiza el contenido de terceros y respeta los términos de uso públicos de la API de Wallhaven.
- Si eres autor de alguna imagen mostrada a través de la app y tienes alguna inquietud sobre su uso, el contenido en sí vive en Wallhaven, no en este repositorio: puedes gestionarlo directamente desde tu cuenta de Wallhaven. Para cualquier duda relacionada específicamente con cómo Wallwinxs consulta la API, puedes abrir un [issue](../../issues) en este repositorio.

## Sobre el uso de la API

- El uso de la API de Wallhaven desde Wallwinxs es el mismo que tendría cualquier usuario navegando o usando la API públicamente documentada de Wallhaven, ya sea en modo público (sin registro, solo contenido SFW) o con una **API Key personal** que cada usuario obtiene gratuitamente desde su propia cuenta de Wallhaven (ver la sección *API y configuración* del [README](README.md)).
- Wallwinxs no intenta eludir límites de uso, autenticación, ni restricciones de contenido impuestas por Wallhaven.

## Marca y nombre "Wallwinxs"

"Wallwinxs" es simplemente el nombre de este proyecto personal/educativo y no está afiliado, patrocinado ni respaldado por Wallhaven.

## Uso del software

El código fuente de este repositorio se ofrece **gratuitamente** para fines personales y educativos, "tal cual" (*as-is*), sin garantías de ningún tipo. Cualquiera puede revisar, compilar y ejecutar el código bajo esas mismas condiciones.
