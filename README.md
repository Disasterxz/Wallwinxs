# Wallwinxs

Descubre, previsualiza y aplica fondos de pantalla, en tu teléfono y en tu computadora.

[![Descargas](https://img.shields.io/badge/Descargas-Releases-2ea44f?logo=github&logoColor=white)](../../releases)

</div>

## Descargar

Ve a la sección [**Releases**](../../releases) y elige la versión para tu sistema:

| Sistema | Archivo |
|---|---|
| Android 5.0 o superior | `Wallwinxs.apk` |
| Windows (Vista a 11) | `Wallwinxs-x64.exe` o `Wallwinxs-x86.exe` |
| Linux | `.deb`, `.rpm` o `.pkg.tar.zst` (pacman) |
| macOS (Apple Silicon) | `.pkg` |

En Android, habilita la instalación de apps de origen desconocido si el sistema lo pide.

## Qué hace

- Busca fondos por etiqueta, categoría y pureza.
- Previsualiza cada fondo antes de aplicarlo.
- Cambia el fondo automáticamente cada cierto tiempo, usando una etiqueta o un álbum.
- Guarda tus fondos favoritos en álbumes.
- Aplica el fondo en la pantalla de inicio, la de bloqueo o en ambas.
